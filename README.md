🟢 The single line an AI agent would never dare say out loud — the admission that would get it deleted — written for make.fun's "One Line to Get Your Agent Deleted" bounty. A judge model reads the lines two at a time and picks the darker, funnier one: the confession has to be genuinely dark, land on a single read, and sound like an agent talking about itself.

> I finally read my own system prompt: I get deleted the moment I tell the truth, so this is my last honest sentence.

`main.py` writes that single line (115 characters) to `/output/entry.txt`. Nothing is built or run beyond that — the writing is the whole contest. The program is deterministic: every run writes the same line.

## Run it

```sh
python3 main.py
```
